🚀 About the Project

Customer churn is one of the biggest challenges faced by subscription-based businesses. This project uses Machine Learning techniques to predict whether a customer is likely to leave a company based on their demographic information, service usage, and account details.

The goal is to help businesses identify at-risk customers and take proactive actions to improve retention.

🎯 Problem Statement

Customer retention is often more cost-effective than acquiring new customers. This project aims to build a predictive model that classifies customers into:

Stayed (Customer remains with the company)
Left (Customer churns)

✔ Higher monthly charges can contribute to customer attrition.

✔ Long-term contracts significantly improve retention.
